# Verification code / magic link corpus

Test corpus for the extractor that finds the one-time code and the verification
(magic) link in a received message. Each `.eml` is a complete RFC 5322 message as
a mail provider would deliver it (trace and DKIM headers, MIME structure,
transfer encodings), stored byte-exact with CRLF line endings (`.gitattributes`
marks `*.eml` as `-text`).

`manifest.json` lists the expected answer for every file:

- `code`: the one-time code as the user types it. Spaces and hyphens that only
  group characters are removed (`482 913` → `482913`, `Q8W-3ZK` → `Q8W3ZK`), a
  Google-style `G-` prefix is dropped (`G-482913` → `482913`), letter case is kept.
  `null` when the message carries no one-time code. Promo codes, booking references
  (PNR), meeting passcodes, sort codes, postal codes, customer numbers and
  reservation confirmation numbers are not one-time codes.
- `link`: the href of the link whose purpose is to verify, confirm, sign in,
  activate or reset, with HTML entities decoded (`&amp;` → `&`). When the button
  goes through a click-tracking redirect, the expected value is that redirect URL
  as written (noted per sample). `null` for tracking, unsubscribe, help, privacy,
  "review activity", order and join links.
- `lang`, `notes`: language and what makes the sample tricky.

Counts: 69 messages; 34 code only, 10 link only, 3 code and link, 22 neither.

## Provenance

Every sample is synthetic and was written for this repository. None contains real
personal data: people are fictional, phone numbers are placeholders (555-01xx,
zero-filled numbers), IP addresses come from the documentation ranges
(192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24), and every mail domain, link and
address uses reserved names (`*.example`, `*.test`, `example.com/.org/.net`). The
only other host name is `www.w3.org` inside standard XHTML DOCTYPE lines. Sender
brands are invented; some imitate the _shape_ of common transactional templates,
nothing more. Attachments and inline images are tiny placeholder bytes.
